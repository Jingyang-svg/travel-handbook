# travel-handbook · 行程攻略手册

> 出发前的「活」行程网页 —— 朋友拿到链接就能看，手机点开即用。

## ✨ 亮点

- **零打字录入**：机票 / 酒店 / 门票 / 活动的 PDF 或截图陆续发，信息自动提取
- **大倒计时**：顶部每秒跳动的出发倒计时 + 实时天气 + 下一个待办
- **手绘路线图**：SVG 地图按天配色、标出每晚住哪；远机场 / 离岛自动意向化，焦点始终是当天行程
- **智能折叠**：过去的日期自动收起，今天和以后自动展开，打开即见当天
- **一键导航**：点地点唤起 Google Maps；点名称弹出中文介绍 + 拍照参考
- **自动核对**：闭馆日、节假日售罄、需预约点、车程是否合理，逐一排查
- **离线可用**：单文件、零外部依赖，飞机上没网也能看
- **隐私安全**：证件号 / 确认号 / 房间号绝不进公开页

## 📦 你只需提供

| 给什么 | 说明 |
|---|---|
| 订单凭证 | 机票、酒店、门票、活动的 PDF 或截图，可陆续发 |
| 基本信息 | 城市、天数、人数 |
| （可选）拍照参考 | 需要时扫码登录小红书协助采集 |

## 📱 产出效果

- 顶部：倒计时（天/时/分/秒）· 实时天气 · 当前待办
- 总览地图：多城配色路线 + 每晚住宿点
- 逐日行程：时间轴 + 可展开当日地图 + 交通方式图标
- 已确认卡片：机票 / 酒店 / 门票
- 待办清单 + 实用贴士 + 备份美食攻略

## 🛠 技术特点

- **数据 / 引擎分离**：模板引擎固定，每趟只写一份 `guide_data.js`
- 响应式，桌面 + 手机双端自检
- 白天 / 黑夜自动换配色

## English

> A *living* itinerary page for the trip ahead — share the link, friends open it on their phone.

- **No typing**: forward flight / hotel / ticket PDFs or screenshots, info is extracted automatically
- **Live countdown**: big ticking countdown to departure + real-time weather + next to-do
- **Hand-drawn map**: SVG route colored by day, marking each night's stay; distant airports / islands de-emphasized so the focus stays on today
- **Smart folding**: past days collapse, today onward expand — open straight to "now"
- **One-tap navigation**: tap a place → Google Maps; tap its name → Chinese intro + photo tips
- **Auto fact-check**: closing days, sold-out holidays, reservations, drive times
- **Offline**: single file, zero dependencies, works on the plane
- **Private**: no ID / confirmation / room numbers ever in the public page
