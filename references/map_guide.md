# 地图指南

地图全部是**手绘感内联 SVG**，无地图底图、无外部依赖、离线可看。两类：

- **总览图 `cityMap(city)`**：每座城市一张，按天用不同颜色叠画全部路线，标出每晚住宿；远距机场 / 离岛意向化。
- **当日路线图 `dayMap(day)`**：每天一张，放大聚焦当天点位，含街道、交通站点、河流、餐饮 / SPA / 交通方式图标；转场段意向化。

## 投影

统一用 **Web Mercator**（`mercXY(lat,lng)`），把经纬度映射到画布：

- `makeProj(cfg)`：**拉伸铺满**取景框，用于总览图（总览画布比例固定，允许轻微拉伸）。
- `makeProjContain(cfg)`：**等比、居中（fit-contain）**，用于当日聚焦图，不拉伸、不变形。

`cfg` 即 `VIEW[city]`：`{W,H,pad,latMin,latMax,lngMin,lngMax}`。
坐标约定注意：轮廓 `GEO` / 街道 `ROADS` 用 `[lng,lat]`，河流 `RIVER` 用 `[lat,lng]`。

## 总览图绘制顺序（cityMap）

1. 背景圆角矩形（海滨城市填海色 `--sea`，内陆城市填 `--map-bg`）。
2. 海滨城市画 `GEO_PK` 各闭合环（陆地 + 海岸线）；曼谷画平滑 `RIVER`。
3. `flyMarks`：飞来 / 飞返 / 船程的图缘标注（灰虚线 + 飞机 / 船图标 + 文字）。
4. 路线：先画宽光晕（半透明、宽 9），再画主线（宽 4）；`dash` 段画虚线。
5. `marker`：机场 / 酒店 / 餐饮 SPA / 景点各有不同图形。
6. `label`：除 `MINOR` 外都标文字，偏移取 `LABEL_ADJ`。
7. `compass` 指北针。

总览路线来自 `BK_LINES` / `PK_LINES`：每条 `{c,ids,dash?}`，
`ids` 按顺序连点。同一天的环线（如 D1 老城一圈）用当天颜色首尾闭合；
跨城 / 远距段（去机场、去水门寺）用 `dash:DASH` 虚线表达意向。

## 当日图绘制顺序（dayMap）

当日图的取景框**由当天核心点自动计算**，无需手填 VIEW：

1. 汇总点：`route` + 当晚 `hotel`。
2. 按 `cut` 分 `mainIds`（核心，真实坐标）与 `flyIds`（转场，意向化）；`anchorId = ids[cut]`。
3. 从 `EDGE_DAY` 分出 `edgeIds`（远距点，如皮皮岛）与 `core`（真实坐标）。
4. 用 `core` 的经纬度 min/max + 26% padding 算取景范围（最小跨度 0.014，宽高比 clamp 在 0.85–2.2）。
5. 有转场 / 边缘点时主图宽 `mainBand`（桌面 68%、手机 74%），右侧留意向化区。
6. `makeProjContain` 等比投影，然后分层绘制：
   - 背景、陆地轮廓 / 河流；
   - **街道网** `ROADS_*`（浅色肌理，粗干道 / 细支路）；
   - **交通站点** `STATIONS`（BTS 绿 / MRT 蓝 / ARL 红，自动跳过与核心点距离 <20 的，避免遮挡）；
   - 主线光晕 + 实线；
   - **主线段交通方式图标**（`DAY_MOVE.seg`，步行不画、距离 <26 不画）；
   - 边缘段、转场段灰虚线 + 飞机 / 交通图标（`DAY_MOVE.fly`）；
   - marker、标签（当日图用 `DAY_LBL`）。

## 意向化：大跨度不按真实比例

当某天含机场、离岛等远距点时，真实比例会把当天的核心点挤成一团。处理：

- **`cut`（推荐）**：把「去机场 / 离岛」及其后的点设为 flyIds，画在右侧图缘，
  与主图用灰虚线 + 飞机图标连接，只表达「从这里转场飞去某地」，不表达真实距离。
- **`EDGE_OV` / `EDGE_DAY`**：把个别离群点固定到图缘坐标 `[x,y]`，虚线引线。
  总览图的机场、当日图的皮皮岛用此法。
- **`flyMarks`**：总览图上把「北京飞来 / 飞返北京」直接标注在图缘。
- 意向段统一用灰色 `--map-fly`、虚线 `4 6`，视觉上明显弱于当天彩色实线，
  确保**视觉焦点是当天实际游玩的几个点**。

判断标准：打开图，第一眼应看到当天的核心行程；机场 / 离岛只是角落的一个「去向」标记。

## marker 种类

| 类型 | 判定 | 图形 |
| --- | --- | --- |
| 机场 | `AIRPORTS[pid]` | 灰圆角方块 + 白色飞机 |
| 酒店 | `HOTEL_COLOR[pid]` | 彩色旗杆 + 落点圆环 |
| 餐饮 | `CAT[pid]==='food'` | 圆环 + 餐具图标 |
| SPA | `CAT[pid]==='spa'` | 圆环 + 按摩 / 莲花图标 |
| 景点 | 其余 | 圆环描边落点 |

每个 marker 都包一个透明 `.mp-hit` 大圆扩大点击区，带 `data-nav`，点击唤起导航；
点名称 / 景点 marker 弹出中文介绍弹窗。

## 防遮挡规则（务必逐一核对）

1. **标签偏移**：`LABEL_ADJ`（总览）/ `DAY_LBL`（当日）设 `[dx,dy,anchor]`，
   近点的标签分别推向不同方向（一个 `start` 向右、一个 `end` 向左）。
2. **次要地点 `MINOR`**：地缘密集、又非重点的点（如密集区的小寺 / 海滩）不常驻文字，marker 仍可点。
3. **站点自动避让**：STATIONS 离核心点 <20px 自动不画。
4. 截图后逐张检查：标签不压 marker、不压彼此、不被画布边缘裁切。
   边缘被裁的点把标签 anchor 改回画布内侧（最左点用 `start`、最右点用 `end`）。
5. 近点标签仍相撞时，优先用 `cut`/`EDGE` 把远距点意向化腾出空间，而不是把核心点也缩小。

## 新增 / 改变城市数量

引擎默认是**双城**（模板里 `bk`/`pk`）。城市数变化属于「结构变化」，需动模板这几处
（单城就删一组、三城就复制一组）：

1. `PLACES` 补齐该城全部地点（坐标逐一核对）。
2. `VIEW` 加一组取景框；新增 `GEO_XX` 海岸线 / 轮廓环（海滨城市）。
3. 准备 `ROADS_XX`、（若有）`STATIONS`、河流；加一份 `XX_LINES` 总览路线。
4. **顶部地图 tab**（HTML 的 `.map-tabs`）：加 / 删一个 `.map-tab[data-city="xx"]`。
5. **`renderMap`**：
   - `om.innerHTML` 里加 / 删一个 `<div id="map-xx">` 容器；
   - tab 点击切换里加对应 `map-xx` 的显隐。
6. **`cityMap(city)`** 里按 city 选择 geo / lines / roads / 河流（现按 `city==='pk'` 二分，
   改成在分支里补 `city==='xx'`）；`flyMarks(city)` 同样补该城的飞来 / 飞返标注数组。
7. 每天的 `mapCity` 指向城市 key；跨城转场天设 `cut`。
8. `WX_CITIES` 加天气城市与在城时间区间。
9. 构建后截图，按防遮挡清单逐项核对总览 + 每个当日图。

> 若希望彻底「只换数据、城市数也自动」，可在数据里加一份城市注册表
> `CITIES:[{key,n,en,geo,lines,roads,river,flyMarks}]`，让 `renderMap`/`cityMap` 遍历它；
> 这是一次性的引擎增强，做完后无需再动模板。

## 调试图层

- 在页面控制台直接调用 `dayMap(DAYS[k-1], 340)` 看某天 SVG 字符串；
  `cityMap('bk')` 看某城总览。
- 某个点位置不对：先查 `PLACES[id].lat/lng`，再查是否被 `EDGE_*` 固定到了图缘。
- 某条线缺失：查 `LINES.ids` / `DAYS.route` 里是否含该 key、拼写是否一致。
- 改完数据必须重新 `build`，并对桌面 + 手机双端截图复检。
